# Saini Info Solutions

Offline-first Flutter starter app for billing and stock management.

## Included
- Dashboard
- Product/stock register
- Low stock and nil stock indicators
- Customer register with mobile number and balance field
- Sale bills with automatic bill number
- Stock reduction on sale
- Today's sales
- PDF/print preview
- Local offline storage

## Build APK
1. Install Flutter and Android Studio on a PC.
2. Run `flutter pub get`
3. Run `flutter build apk --release`
4. APK will be generated under `build/app/outputs/flutter-apk/app-release.apk`

This is a working starter implementation; GST, purchase, repair module, payment ledger, backup/restore and advanced invoice customization can be added next.
